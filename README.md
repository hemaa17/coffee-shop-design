# ☕ The Roastery - Coffee Shop App Design
"UI/UX High-Fidelity Prototype for a Coffee Shop App."

Project Overview:
"The Roastery" is a mobile coffee ordering app designed to focus on micro-interactions and smooth user flow.

 The project file(.fig): https://drive.google.com/file/d/1JQsnppq9dee1JfN7pF4D8C8wO7KiT9t7/view?usp=sharing

 Key Features
>Smart Animation:*Seamless transitions between the Menu and Product Detail pages.
>Logic & State:Functional "Add to Cart" counter (1, 2, 3...) built with Figma Variables.
>efficiency:Used "Paste to Replace" workflow to manage assets across 15+ screens.
